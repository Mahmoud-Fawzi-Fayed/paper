For FedFACS reviewer comments, the user does not accept "we admit the limitation" as a resolution. Each comment needs an actual change (method, equation, experiment) and a short declaration of what was done, written in Springer Nature Q1 journal style (Before/After with location, declared notation, evidence).

**Why:** the user said admission-only answers weaken the paper's position and invite more comments (they objected to sentences such as "no stability guarantee is established" and "luck, not proof"). Limits may still be stated once, in place, but only after the fix and its evidence.

**How to apply:** for every open comment, propose and test a real fix first (see [[feedback-no-fabrication]]); report honestly if the fix does not work. Never alter measured numbers to make FedFACS look better. Currently open as "admitted only": R2-05 scale mismatch (rank-normalised priority + age guard under test, seq11_norm.log), R2-04 controller necessity, R1-04/R2-06 KL not the strongest predictor, R2-18 no convergence theory, R1-05 variance penalty not a noise detector, R2-17 trust.
